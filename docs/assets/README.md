Captura real da janela Tauri nativa com o Painel e seus seis Módulos renderizados pela UI do app. Capturada em 02/11/2026 em 1100 × 700, tema escuro, usando `npm run dev:fixtures` com as variantes sintéticas `readme` em cada Módulo. A origem e os campos substituídos dessas variantes estão em [`src/lib/fixtures/README.md`](../../src/lib/fixtures/README.md).

Os valores, nomes de projeto, repositório, quadro, listas, sessões e leituras da imagem são sintéticos; não são dados de contas ou do computador de origem, nem uma captura da versão distribuída. A imagem foi inspecionada visualmente e é um PNG RGB de 1100 × 700, sem texto EXIF. O JSON temporário de métricas ficou fora do repositório.
