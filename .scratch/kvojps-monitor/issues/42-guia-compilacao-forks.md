# 42: Guia para compilar e manter forks

**What to build:** completar `docs/desenvolvimento.md` em pt-BR para que outra pessoa consiga partir de um clone limpo, executar, testar e compilar o app ou seu próprio fork.

**Status:** ready-for-agent

- [ ] Documentar ferramentas e dependências de sistema para o ambiente suportado (Ubuntu 24.04+, GNOME), a partir da configuração real do projeto
- [ ] Documentar instalação das dependências do projeto, execução do app real e uso do modo de fixtures, distinguindo os efeitos de cada modo
- [ ] Documentar os comandos de verificação usados pelo CI e os comandos para gerar os pacotes locais disponíveis
- [ ] Verificar os passos a partir de um clone limpo ou ambiente isolado e registrar limitações da validação
- [ ] Preservar as instruções existentes de protótipo, fixtures e captura; explicar como gerar imagens sanitizadas do app
- [ ] Explicar que o projeto não recebe contribuições externas; quem quiser adaptar ou manter uma versão própria pode fazer fork conforme MIT
- [ ] Não criar fluxo de contribuição, templates de PR ou convites para enviar alterações ao projeto original
- [ ] Incluir link para o guia no README pelo ticket 23
